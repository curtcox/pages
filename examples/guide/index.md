# How Pages Online works

A small workspace for HTML, CSS, JavaScript, and Markdown. No account, server, or build step needed.

[Files & pages](files.md) · [The sandbox](sandbox.md) · [Sharing & offline](sharing.md)

## Start with something small

Choose **More → New project** for an HTML project, blank HTML, one Markdown page, or a Markdown site. Or load a sample from the gallery.

Edit a file and the preview updates 500 ms after you stop typing. Turn off **Auto-refresh** to run only when you press **Run** or **Ctrl+Enter** (Command+Enter on Mac).

On a phone, use **Preview / Code / Console**. The file tabs scroll sideways. Double-click or long-press a tab for file actions.

## Find your way

Use the + button to add a file. Use **File ⋯** to rename, delete, or choose the entry page. The preview has Back, Reload, device widths, and Open page.

Open Console to see logs and errors, follow file/line links, or evaluate an expression in the preview.
